10/17일의 블로그이다

[25238번: 가희와 방어율 무시](https://www.acmicpc.net/problem/25238)

![](./img/img.png)

풀이  
조건 하나를 확인해주고  
입력, 출력으로 끝낼 수 있는 문제이다  

시간 복잡도 : $O(1)$  
소요 시간 : 30초  
아쉬운 점 : 영어 공부 열심히 했다  
전체적인 감상 : 내일 시험 잘보자

```cpp
#include<stdio.h>
int main(){
   int a,b;
   scanf("%d %d",&a,&b);
   printf("%d",(a*(100-b)>=10000?0:1));
}
```
